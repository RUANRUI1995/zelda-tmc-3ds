- Upstream v0.4.7 plus this fork's Chinese support: the tag's trailing `c` marks the Chinese build. It replaces v0.5.0, whose page is retired.
- A Japanese baseline ships as its own package (`tmc-3ds-v0.4.7c-jp.cia`, "Minish Cap 3DS (JP)"), with its own title ID so it installs next to the USA one. It is the package a Japanese ROM needs, and the only one that can start the Angel Team Chinese SP4 patch.
- Chinese ROMs play: the patch renumbers the character codes, makes one of them variable length and moves the wide glyphs to another bank, and the port reads the patch's own mapping, so dialogue, menus and item names are not garbled. The ROM is identified by its content (SHA-1) rather than its header, because the patch keeps the Japanese header.
- Saves, save states and the asset cache are kept apart per ROM variant: a Chinese save cannot land in a Japanese game's slot, and a build refuses to load a save state made with another ROM.
- The bottom screen is translated into Chinese, and OPTIONS -> LANGUAGE picks the language of the port's own screens (English, French, German, Spanish, Italian, Chinese) instead of always following the ROM. Cells grow for the taller Chinese type, the option list still scrolls, and no text runs past a border.
- The updater checks this fork instead of tinaut1986's, so a Chinese build is never replaced by the English-only original. RetroAchievements cannot identify a patched ROM: use the USA or JP package with a clean ROM for achievements.
