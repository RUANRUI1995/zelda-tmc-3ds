- A Japanese baseline now ships as its own package (`tmc-3ds-v0.5.0-jp.cia`, "Minish Cap 3DS (JP)"), with its own title ID so it installs next to the USA one. It is the package a Japanese ROM needs, and the only one that can start the Angel Team Chinese SP4 patch.
- Chinese ROMs play: the SP4 patch renumbers the character codes and makes one of them variable length, and moves the wide glyphs to another bank. The port reads the patch's own mapping, so dialogue, menus and item names are no longer garbled.
- The ROM is identified by its content (SHA-1 profile) instead of its header country code. The Chinese patch keeps the Japanese header, so the header alone cannot tell it apart from a clean Japanese ROM.
- Saves, save states and the asset cache are kept apart per ROM variant: a Chinese save can no longer land in a Japanese game's slot, and a build refuses to load a save state made with another ROM.
- The bottom screen is translated into Chinese, and OPTIONS -> LANGUAGE picks the language of the port's own screens (English, French, German, Spanish, Italian, Chinese) instead of always following the ROM. Taps on chips and the taller Chinese type are accounted for: cells grow, the option list still scrolls, and no text runs past a border.
- The updater checks this fork instead of tinaut1986's repository, so a Chinese or Japanese build is never replaced by the English-only original. `CHECK FOR UPDATE` reads the two packages here and offers the one this install is.
- RetroAchievements does not work on a patched ROM: the patch rewrites the game, so the server cannot identify it. This is expected and not a bug in the port. Use the USA or Japanese package with an unpatched ROM if you want achievements.
